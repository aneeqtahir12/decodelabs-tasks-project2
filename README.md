# Data Science Project 2 - Decodelabs Tasks

This repository contains my second Data Science project completed as part of the Decodelabs internship tasks.

## Project Overview

This project focuses on data analysis using Python. It includes data loading, data cleaning, and exploratory data analysis to understand patterns and insights from the dataset.

## Tasks Completed

### Task 1: Data Loading and Understanding

* Loaded dataset using Pandas (read_csv)
* Viewed dataset using head()
* Checked dataset structure using info() and shape

### Task 2: Data Cleaning

* Checked missing values using isnull().sum()
* Identified and handled null values
* Checked duplicate values
* Prepared clean dataset for analysis

### Task 3: Exploratory Data Analysis

* Generated statistical summary using describe()
* Analyzed data distribution and patterns
* Observed relationships between different variables
