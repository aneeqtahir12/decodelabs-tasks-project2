# Data Science Project 2 - Decodelabs Tasks

This repository contains my second Data Science project completed as part of the Decodelabs internship.

## Project Overview

This project focuses on performing data analysis using Python. It includes key steps such as data loading, data cleaning, exploratory data analysis, and basic data manipulation to extract useful insights from the dataset.

## Tasks Completed

### Task 1: Data Loading and Understanding

* Loaded the dataset using Pandas (`read_csv`)
* Displayed the first few rows using `head()`
* Checked dataset structure using `info()` and `shape`

### Task 2: Data Cleaning

* Identified missing values using `isnull().sum()`
* Handled null values appropriately
* Checked and removed duplicate records
* Prepared a clean dataset for further analysis

### Task 3: Exploratory Data Analysis

* Generated statistical summary using `describe()`
* Analyzed data distribution and patterns
* Observed relationships between different variables

### Task 4: Data Manipulation

* Selected and filtered specific data using conditions
* Modified and updated columns where necessary
* Applied basic transformations to the dataset
* Organized the data for better analysis
